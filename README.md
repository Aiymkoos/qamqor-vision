## Что работает сейчас

* **Распознавание обстановки.** Снимок с камеры разбирается моделями Google ML Kit
  **на устройстве**: без интернета, без API-ключа и без серверной части. Метки выше
  порога уверенности 0.65 переводятся на казахский и русский и озвучиваются.
  Снимок удаляется сразу после обработки — фотографии не сохраняются и никуда
  не отправляются.
* **Положение препятствий.** Детекция объектов даёт рамки в кадре, из них считается
  «слева / по центру / справа» и «близко / далеко»: «Препятствие по центру, близко.»
  Положение и содержимое сообщаются **раздельно** — базовая модель детекции
  классифицирует слишком грубо, и связывать рамку с меткой значило бы рисковать
  фразой «стол слева», когда слева стул.
* **Голосовой вывод.** Синтез речи через `flutter_tts` с прерыванием предыдущей фразы,
  кнопками остановки и повтора.
* **Управление вслепую.** Панель занимает бо́льшую часть экрана и сама работает
  кнопкой: двойное касание описывает обстановку, так что попадать пальцем в кнопку
  не нужно. Рядом объявлено семантическое действие — TalkBack и VoiceOver
  перехватывают жесты, и без него функция не досталась бы тем, для кого сделана.
  О жесте приложение сообщает голосом при запуске.
* **Настройки переживают перезапуск.** Язык и скорость речи сохраняются. Скорость
  переключается кнопкой по трём ступеням и называется вслух уже на новой скорости —
  ползунок пришлось бы вести пальцем и смотреть, куда он доехал.
* **Двуязычность.** Переключение казахского и русского для интерфейса и голоса.
  Если казахского голоса нет на устройстве, приложение сообщает об этом вслух
  и переходит на запасной, вместо того чтобы молча замолчать.
* **Доступный интерфейс.** Контрастность около 11:1 (тёмно-синий / ярко-жёлтый) при
  минимуме 4.5:1 для WCAG AA, зоны нажатия 88dp при минимуме 44dp, подписи `Semantics`
  для TalkBack и VoiceOver, тактильный отклик на нажатие, дублирование речи на экране.

### Принцип: не выдумывать

Незрячий пользователь не может перепроверить ответ глазами, поэтому приложение
никогда не заполняет пробелы догадками. Если модель ничего не узнала, или все её
метки оказались вне словаря перевода, или камера недоступна — оно прямо говорит
об этом и предлагает, что сделать, вместо правдоподобного вымысла.

Покрыто тестами (`flutter test`), включая разбор фразы, поведение при ошибках
камеры и подписи для скринридера.

### Структура кода

```
lib/
├── main.dart                     # точка входа
├── theme/app_theme.dart          # высококонтрастная тема WCAG
├── l10n/
│   ├── app_strings.dart          # строки интерфейса на kk и ru
│   └── object_labels.dart        # словарь меток ML Kit → kk / ru
├── services/
│   ├── speech_service.dart       # обёртка над синтезом речи
│   ├── vision_service.dart       # камера и распознавание на устройстве
│   └── scene_narrator.dart       # сборка фразы из меток

└── widgets/big_action_button.dart
```

> **Платформы:** после подключения ML Kit приложение работает только на Android и iOS —
> ML Kit не поддерживает веб и десктоп.

## О проекте

**Qamqor Vision** — задуманное мобильное приложение для повышения автономности и безопасности
людей с нарушениями зрения. Идея: с помощью алгоритмов компьютерного зрения в реальном времени
анализировать окружающую обстановку и озвучивать её пользователю.

**Миссия проекта:** создать доступную инклюзивную среду в Казахстане, стерев границы между
визуальной информацией и людьми, которые не могут её воспринимать.

## Задуманные возможности (дорожная карта)

* [x] **Двуязычная поддержка:** локализация интерфейса и голосового движка на **казахском** и **русском** языках.
* [x] **Smart Vision (ИИ-распознавание):** идентификация бытовых предметов и мебели.
* [ ] **Текст-в-речь (OCR):** чтение вывесок, этикеток продуктов, документов и упаковок лекарств.
  **Заблокировано, и это разбиралось подробно:**
  1. On-device распознавание текста ML Kit поддерживает только латиницу, китайский,
     деванагари, японский и корейский — [кириллицы в списке нет](https://developers.google.com/ml-kit/vision/text-recognition/v2).
     Значит, ни казахский, ни русский текст им не прочитать.
  2. Единственный офлайн-движок для кириллицы — Tesseract. Но его основная обвязка
     [`flutter_tesseract_ocr`](https://pub.dev/packages/flutter_tesseract_ocr) в своём
     `android/build.gradle` вызывает `jcenter()` и прибита к Android Gradle Plugin 7.1.2.
     JCenter закрыт с 2021 года, метод убран из Gradle 9 — сборка падает на этапе
     конфигурации. Плюс плагин тянет 14 МБ готового `.aar`.
  3. Альтернатива [`flusseract`](https://pub.dev/packages/flusseract) собирает Tesseract
     из исходников (~10 минут на сборку), последний релиз 0.1.3 двухлетней давности.

  Реальные пути вперёд: поддерживаемый форк обвязки Tesseract, облачный OCR
  (нужен ключ, оплата и интернет — противоречит офлайн-работе остальных функций)
  либо Apple Vision только под iOS.
* [x] **Безопасность:** предупреждение о препятствиях с указанием стороны и близости.
  Что именно за препятствие — не называется: базовая модель детекции для этого
  слишком груба. Ступени и открытые двери отдельно не распознаются.

## Технологический стек

**Используется сейчас:**

* **Flutter / Dart** — приложение под Android и iOS.
* **Google ML Kit** — разметка кадра (`google_mlkit_image_labeling`) и детекция
  объектов (`google_mlkit_object_detection`) на устройстве, офлайн и без API-ключа.
* **camera** — съёмка кадра для распознавания.
* **flutter_tts** — синтез речи средствами устройства.
* **shared_preferences** — сохранение языка и скорости речи.

**Планировалось для полной версии:**

* **Backend:** Python (FastAPI) для тяжёлых вычислений.
  Пока не понадобился: распознавание целиком уместилось на устройство.
* **AI/ML:** YOLOv8 — для определения положения предметов и предупреждения о препятствиях.
* **Database:** Firebase (авторизация и хранение настроек).

> Изначально на OCR планировался Google ML Kit, но его on-device движок не умеет
> кириллицу — см. отметку в дорожной карте выше.

## UI/UX концепция

Интерфейс спроектирован с учётом стандартов **WCAG 2.1**:

* Высокая контрастность (тёмно-синий / ярко-жёлтый), около 11:1.
* Увеличенные зоны нажатия — 88dp при минимуме 44dp по критерию 2.5.5.
* Подписи `Semantics` для скринридеров (TalkBack и VoiceOver).
* Тактильный отклик на каждое нажатие — подтверждение для тех, кто не видит
  изменения состояния кнопки.

## Установка и запуск

Требуется установленный [Flutter SDK](https://docs.flutter.dev/get-started/install)
и **физическое устройство** на Android или iOS: распознавание работает с камерой,
а эмулятор отдаёт синтетический кадр.

```bash
# Клонируйте репозиторий
git clone https://github.com/Aiymkoos/qamqor-vision.git

# Перейдите в папку проекта
cd qamqor-vision/qamqor_vision

# Установите зависимости
flutter pub get

# Запустите приложение
flutter run
```

## История проекта

*Идея проекта родилась из личного опыта. Моя сестра потеряла зрение на один глаз после
осложнений при родах, вызванных диабетом. Она лишилась возможности выходить на улицу
самостоятельно — не из-за полной слепоты, а из-за страха и отсутствия инструментов, которые
помогли бы ориентироваться. Qamqor Vision — моя попытка вернуть ей и таким, как она, эту свободу.*
