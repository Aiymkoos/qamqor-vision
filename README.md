## О проекте

**Qamqor Vision** — это мобильное приложение, разработанное для повышения автономности и безопасности людей с нарушениями зрения. Используя передовые алгоритмы компьютерного зрения (Computer Vision), приложение в реальном времени анализирует окружающую обстановку и озвучивает её пользователю.

**Миссия проекта:** Создать доступную инклюзивную среду в Казахстане, стерев границы между визуальной информацией и людьми, которые не могут её воспринимать.

---

## Ключевые возможности

* **Smart Vision (ИИ-распознавание):** Идентификация бытовых предметов, мебели, препятствий и людей.
* **Текст-в-речь (OCR):** Мгновенное чтение вывесок, этикеток продуктов, документов и упаковок лекарств.
* **Двуязычная поддержка:** Полная локализация интерфейса и голосового движка на **казахском** и **русском** языках.
* **Безопасность:** Предупреждение о потенциальных угрозах (ступени, открытые двери, препятствия).

---

## Технологический стек

* **Frontend:** Flutter (кроссплатформенная разработка iOS/Android).
* **Backend:** Python (FastAPI) для тяжелых вычислений.
* **AI/ML:** YOLOv8 (распознавание объектов), Google ML Kit (OCR).
* **Database:** Firebase (авторизация и хранение настроек).

## Установка и запуск (для разработчиков)

Чтобы запустить проект локально, выполните следующие команды:

```bash
# Клонируйте репозиторий
git clone https://github.com/username/qamqor-vision.git

# Перейдите в папку проекта
cd qamqor-vision

# Установите зависимости Flutter
flutter pub get

# Запустите приложение
flutter run

```

## История проекта

Идея проекта родилась из личного опыта. Моя сестра потеряла зрение на один глаз после осложнений при родах, вызванных диабетом. Она лишилась возможности выходить на улицу самостоятельно — не из-за полной слепоты, а из-за страха и отсутствия инструментов которые помогли бы ориентироваться. Qamqor Vision — моя попытка вернуть ей и таким как она эту свободу.
